- `derive_decision` / `WitnessService.sign_decision`: a decision is a PURE FUNCTION of the request and the DBC's current checkpoint, so the witness DERIVES its decision from its own injected view (the E `witness.decide` logic ported: request recovered from the PBC log and the direct-to-PSC call, digest recomputed, PSC record
  equal, checkpoint fresh and naming a real block, epochs, destination, nonce, both clocks, its own credential evaluation at the checkpoint block with that block's timestamp, the lapsed-credential rule) with the F changes (`expiresAt = min(request.expiresAt, checkpoint.expiresAt)`, no host-clock term), and signs only when the
