## 1. The adapter command
```
cd protocol && python -m hmbc_protocol.adapter_v2_main --deployment <F.json> --abi-dir <D> --schema <S> --schema-sha256 <64 lowercase hex> \
    --schema-revision v2|v2.1 --state-dir <new private 0700 dir> [--allow-governance <FILE>]
```
- The six flags are BUILT, each required, none defaulted, exit 2 on a missing one. Which schema file, hash and revision a run uses is named by your execution FREEZE; this contract only fixes that they are passed explicitly and exactly. Interpreter: the root-lock Python 3.13, `cwd = protocol/`, no `PYTHONPATH`; the module reads no environment variable (tested).
- Startup failure is BUILT (A2-0073): ONE JSON object `{"error": {"code", "message", "reason"?}}` on stderr, nothing on stdout, exit 2, no traceback, nothing left behind. **A refused startup spawns no child and writes no pid file** (PROPOSED for P1; the supervisor already refuses before spawning anything if its own checks fail).
- **P2, optional and TEST-ONLY: `--allow-governance <FILE>`. This is an ADDITION to the command line.** The adapter passes the same path to every witness as `--allow-governance <FILE>` (a JSON array of `[action, root, [admins]]`; with none, a witness signs no governance action; the adapter validates the file before spawning anything). Why: in the supervised layout the adapter, not the runner, starts the witnesses, so this is the runner's only way to give them their local approval list (rows F-24, F-30). Rejected alternatives: an environment variable (modules read none, tested); a hidden fixed path under the state directory (an input that appears in neither the command line nor the FREEZE); a request field of `collect_governance` (would change the frozen schema and let the proposer approve its own action).

## 3. Clock and timing (BUILT in the transport, constants BUILT in `pool_core`/`adapter_v2_witness`)
- The transport's only clock is `time.monotonic_ns`, reported in whole milliseconds, floored, since the first send of a collection; no wall clock enters the pool. Ledger time comes from chain reads (the DBC's latest block timestamp; the PBC's for a governance action).
- Equal-millisecond rule: a timer due at millisecond `t` fires before a reply at `t`; a reply at the 5000 ms reply timeout is late; a reply at or after the deadline is ignored. A tie at exactly one millisecond is a measure-zero event on a loaded host and scheduling jitter is larger than the rule's resolution: **the runner must use the `collection` evidence the adapter returns, not recompute outcomes from its own timestamps.**
- Constants: reply timeout 5000 ms; collection cap 10000 ms; 2 s reserve (a collection with 2 s or less of validity is `EXPIRED` and contacts nobody); quorum 3 of 4 (a constant); receipt window = DBC latest timestamp + 60 s; single-witness mode one write, one reply, 5 s; a reply line over 1 MiB is malformed.

## 5. What the runner MAY rely on, and MUST NOT
MAY (once P1/P2/P3 are ACKed and built): the command of section 1 and its closed refusal; after a successful start, four pid files, four stores, four stderr files and the key worker at `<state>/worker/`; index, label and address agree with `fixture.witnessSet`; per-witness control by pid file after the `/proc` check; no respawn in one run; children exit when the adapter dies; the adapter's `collection` evidence (four outcomes in index order, `silent` = zero replies) and `witnessIndex` mode; the read-only exporters (`witness_state --evidence|--binding`, `worker_log [--binding]`), which carry no key and redact tokens to digests; the timing rules of section 3.
MUST NOT: use or derive a witness key or the worker's secrets (keys are TEST-ONLY and derivable from public labels, so custody is procedural role separation, not secrecy; the runner holds no witness key, the E rule unchanged); read a running witness's database for anything but the documented exporters, read a raw release token, or write to a witness pipe; signal anything but a witness child identified by its pid file and `/proc` check (never `pkill`); treat a missing reply as a denial (a missing quorum is `QUORUM_UNAVAILABLE`); treat a symbolic response as ABE, confidentiality, delivery or consensus (Anvil is not Byzantine consensus); use evidence from a mutant deployment as safety evidence (A1-0106: bit 1 and bit 5 make the death evidence false); rely on a stderr file being empty, on an automatic restart, on a readiness handshake or on a cold-start time.
